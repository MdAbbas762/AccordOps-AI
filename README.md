# AccordOps AI

**AI-Powered Contract Intelligence & Operational Control Platform**

AccordOps AI is a flagship AI automation system that converts signed business agreements into monitored operational obligations.

The platform will:

- ingest contracts, SOWs, and amendments
- extract structured obligations using AI
- allow human verification
- monitor connected business systems
- detect SLA, billing, deliverable, and renewal exceptions
- investigate exceptions using evidence
- route important actions through human approval
- automate approved downstream actions
- maintain a full audit trail

## Core Stack

- Frontend: Next.js + Tailwind CSS
- Backend: Python + FastAPI
- Database/Auth: Supabase PostgreSQL + Supabase Auth
- AI: Gemini API
- Automation: n8n Community Edition
- Containerization: Docker
- Integrations: Jira Service Management, HubSpot, Stripe Test Mode, Slack
